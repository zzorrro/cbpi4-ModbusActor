# CBPi4 Modbus Actor (RS485 0-10V)

Плагин для CraftBeerPi 4, позволяющий управлять мощностью нагрева через внешний аналоговый модуль RS485-to-0-10V по протоколу Modbus RTU.

## 🎯 Особенности
- **Плавное регулирование**: Поддержка 12-битного (0-4095) и 16-битного (0-10000) разрешения.
- **Безопасность**: Автоматическое отключение мощности (0%) при потере связи с Modbus-устройством.
- **Гибкость**: Настройка порта, скорости, адреса устройства и номера регистра прямо из интерфейса CBPi4.
- **Совместимость**: Работает с любыми логиками нагрева (SmartLogic, DirectPWMBoil, PID), так как реализует стандартный интерфейс актора CBPi4.

## 📦 Установка

Убедитесь, что у вас установлена зависимость `pymodbus`, затем установите плагин:

```bash
# Установка зависимости
pipx runpip cbpi4 install pymodbus

# Установка плагина из этого репозитория
pipx runpip cbpi4 install git+https://github.com/zzorrro/cbpi4-ModbusActor.git

# Перезапуск CBPi4
sudo systemctl restart craftbeerpi.service
