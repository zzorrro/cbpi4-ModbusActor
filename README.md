# CBPi4 Modbus Actor (RS485 0-10V)

Плагин для CraftBeerPi 4, позволяющий управлять мощностью нагрева или частотным преобразователем через внешний аналоговый модуль RS485-to-0-10V по протоколу Modbus RTU. Для работы необходим преобразователь интерфейсов USB-RS485 (чип CH340), который подключается к Raspberry PI через USB-порт.

## 🎯 Особенности
- **Плавное регулирование**: Поддержка 12-битного (0-4095) и 16-битного (0-10000) разрешения.
- **Автоматическое переподключение**: При потере связи плагин самостоятельно попытается восстановить соединение.
- **Безопасность**: Автоматическое отключение мощности (0%) при остановке шага или перезапуске CBPi4.
- **Гибкость**: Настройка всех параметров (порт, скорость, адрес, регистр) прямо из веб-интерфейса CBPi4.
- **Совместимость**: Работает с любыми логиками нагрева.

## 📦 Установка

### Установка и отладка
```bash

Установка библиотек в окружение CBPI4
pipx runpip cbpi4 install pymodbus pyserial

Добавьте текущего пользователя в группу dialout (имеющую доступ к COM-портам)
sudo usermod -a -G dialout $USER

Перезагрузка системы для применения прав доступа
sudo reboot

Установка плагина из этого репозитория
pipx runpip cbpi4 install git+https://github.com/zzorrro/cbpi4-ModbusActor.git

Проверьте, видит ли система адаптер
ls -l /dev/ttyUSB*

По умолчания задается порт: /dev/ttyUSB0, если порт называется иначе (например, ttyUSB1), укажите его в настройках.

Если к вашей Raspberry Pi уже подключены другие USB-устройства, адаптер может получить имя `/dev/ttyUSB1` или `/dev/ttyUSB2` вместо `/dev/ttyUSB0`, а также при перезагрузке имена портов могут меняться местами.
Для правильной инициализации нужно добавить в настройки уникальное имя порта.

Узнать уникальное имя порта
 ls -l /dev/serial/by-id/

Вы увидите вывод вроде этого:
lrwxrwxrwx 1 root root 13 ноя  6 21:00 usb-1a86_USB_Serial-if00-port0 -> ../../ttyUSB1

Вместо /dev/ttyUSB0 в настройках плагина CBPi4 нужно прописать полное имя из этой папки:
/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0
