# CBPi4 Modbus Actor (RS485 0-10V)

Плагин для CraftBeerPi 4, позволяющий управлять мощностью нагрева через внешний аналоговый модуль RS485-to-0-10V по протоколу Modbus RTU.

## 🎯 Особенности
- **Плавное регулирование**: Поддержка 12-битного (0-4095) и 16-битного (0-10000) разрешения.
- **Автоматическое переподключение**: При потере связи плагин самостоятельно попытается восстановить соединение.
- **Безопасность**: Автоматическое отключение мощности (0%) при остановке шага или перезапуске CBPi4.
- **Гибкость**: Настройка всех параметров (порт, скорость, адрес, регистр) прямо из веб-интерфейса CBPi4.
- **Совместимость**: Работает с любыми логиками нагрева.

## Если порт называется иначе (например, ttyUSB1), укажите его в настройках.
# Также попробуйте физически переподключить USB-адаптер или перезагрузить систему:

##№ Ошибка: Could not exclusively lock port

# Найдите процесс, удерживающий порт
sudo fuser /dev/ttyUSB0

# Остановите CBPi4 и принудительно освободите порт
sudo systemctl stop craftbeerpi.service
sudo fuser -k /dev/ttyUSB0

# Запустите CBPi4 заново
sudo systemctl start craftbeerpi.service

##№ Ошибка: Permission denied

# Добавьте текущего пользователя в группу dialout (имеющую доступ к COM-портам)
sudo usermod -a -G dialout $USER

# Перезагрузите систему для применения прав
sudo reboot
